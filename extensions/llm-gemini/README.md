# @ethosagent/llm-gemini-native

`LLMProvider` for Google's native Gemini `streamGenerateContent` API (provider `gemini-native`); the default `gemini` alias goes through `@ethosagent/llm-openai-compat` instead.

**Verified against spec on 2026-09-28 (no live Gemini test).** Gemini 3 thought signatures follow Google's thought-signature documentation: a `thoughtSignature` on a `functionCall` part is remembered per tool-call id and sent back on that same part, byte for byte, on every later request; with parallel calls only the first part is signed; in a sequential turn every step's signature is replayed. Pinned by `src/__tests__/transport.test.ts` and `src/__tests__/thought-signature-spec.test.ts`. Signatures live in the provider instance, so a restart or a failover from another provider leaves calls Gemini never signed. For a `gemini-3*` model the first unsigned `functionCall` of each model turn is sent with Google's documented dummy, `thoughtSignature: "skip_thought_signature_validator"` (`SKIP_THOUGHT_SIGNATURE` in `src/transport.ts`), so Gemini 3 skips validation instead of answering 400. Google notes the model may reason less well over such a call. Other models never get the dummy. Pinned by the 'unsigned functionCall parts in history' cases in `src/__tests__/thought-signature-spec.test.ts`.
